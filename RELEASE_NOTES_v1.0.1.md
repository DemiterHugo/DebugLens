# DebugLens v1.0.1

- Interfaz renovada en tema claro y oscuro, con importación de Logcat destacada
  y acceso directo al historial.
- Diagnósticos más fáciles de leer: ubicación destacada, comprobaciones y un
  botón para compartir o guardar.
- El diagnóstico aparece una vez preparada la interfaz A2UI, con un solo
  desplazamiento al resultado.
- El README explica cómo usar una traza obtenida durante una prueba y qué
  aporta A2UI al diagnóstico.
